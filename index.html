Agent

System prompt

The instructions the model gets before the conversation. A saved change applies from your next message, in the same conversation; sub-agents get it too, with their own instructions added. With Claude, a change makes the next request re-read the conversation without the cache once.

Context

How full the model's context window is, and compaction: the conversation so far is summarized by the same model and the summary takes its place. Files in the VM are not affected.

Token usage this conversation

Input counts uncached input tokens only; cached tokens are under Cache read. Output includes thinking. Claude doesn't report thinking tokens separately (—); OpenAI-style APIs that do show them. Sub-agents are the Delegate tool's; Compaction is the requests that wrote summaries.

Machine

      
Which system the VM runs: its disk (root filesystem) and processor. A change reloads the page to
        start the VM again: the workspace and the skills stay, the chat starts over (export it from the Log tab first to
        restore it after). Each machine keeps its own saved state.

      

        
        
        

        

      

      
Saved state

      
A saved state is the whole running VM. Reloading the page resumes it in seconds instead of booting
        again. One is saved by itself after each cold boot.
